# Organic neural network refinement

## Outcome
Keep the existing page unchanged while making the neural background richer, less geometric, and more natural.

## Changes
- Replace the visible grid pattern with deterministic clustered placement and varied spacing.
- Draw each stable connection as a subtle curved path rather than a straight segment.
- Add a restrained secondary depth layer with fewer, softer nodes and connections.
- Move related nodes in coordinated local groups so the field feels alive without jitter or snapping.
- Preserve mobile performance and the static reduced-motion version.

## Verification
Check the unobstructed phone view across multiple frames, reduced motion, and current build/runtime status.
