# Precision SaaS Copy Recalibration

## Goal
Recalibrate EvoLegal’s English interface copy around contract intelligence, measurable precision, auditability, and speed, while preserving existing layouts, functionality, pricing, and legal safeguards.

## Plan

1. **Reposition the public entry experience**
   - Set the main headline to **“Precision Contract Intelligence.”**
   - Set the supporting line to **“Scan complex agreements, isolate critical exposure, and accelerate deal flow—with enterprise-grade accuracy.”**
   - Standardize the principal actions to **“Run Legal Audit”** and **“Explore Sample Audit.”**
   - Replace broad consumer-oriented claims with concise, enterprise-facing outcomes across the home, services, process, pricing, FAQ, contact, and footer areas.

2. **Standardize Hugo and contract-analysis actions**
   - Use **“Launch Hugo Co-Pilot”** wherever the interface launches Hugo.
   - Reword relevant document and analysis controls with high-certainty verbs such as **Audit**, **Validate**, and **Extract**.
   - Align chat headings, placeholders, status text, navigation labels, dashboard shortcuts, and document controls with the same precise vocabulary without changing their behavior.

3. **Replace Hugo’s starter prompts**
   - Use these four prompts exactly:
     - “Audit liability caps, indemnity triggers, and non-standard terms.”
     - “Draft a balanced NDA aligned with standard commercial terms.”
     - “Extract termination rights, cure periods, and renewal triggers.”
     - “Compare draft against playbook and highlight risk deviations.”
   - Keep the current icon-based prompt presentation and interaction behavior.

4. **Tighten interface micro-copy site-wide**
   - Audit buttons, headings, cards, form guidance, empty states, dialogs, notices, tooltips, loading states, confirmations, and error messages.
   - Keep modal notices and tooltips to no more than two sentences.
   - Remove consumer buzzwords and casual claims, including “easy,” “magic,” “effortless,” and “bureaucracy-free.”
   - Prefer concise language tied to exposure detection, structured review, traceability, turnaround, and verified outputs.

5. **Preserve legal and product accuracy**
   - Retain required informational-use disclaimers, jurisdiction caveats, user-responsibility notices, privacy statements, and plan limits.
   - Refine those passages only for clarity and concision; do not weaken or remove compliance meaning.
   - Do not alter Hugo’s response logic, authentication, pricing values, credits, document generation, or chat behavior.

6. **Validate the finished copy**
   - Search the application for obsolete CTA variants, old headline language, banned buzzwords, and outdated starter prompts.
   - Verify the main public flow, Hugo launcher, dashboard chat entry, dialogs, and mobile labels visually.
   - Confirm the application completes its automated build without errors.

## Technical scope
- Frontend copy and prompt constants only, across public pages, dashboard pages, shared navigation/footer, Hugo chat surfaces, dialogs, tooltips, and feedback messages.
- No visual redesign, data-model changes, or backend behavior changes.
